# Práctica 6 - SAD: AHPSort II

Clasificación de las provincias según su nivel de seguridad (Alto, Medio, Bajo) con AHPSort II.

## Contenido

- `practica6.py`: script que resuelve los 4 ejercicios y dibuja los mapas.
- `datos/`: ficheros de datos de la práctica.
- `mapas/`: shapefiles de Andalucía y de España.
- `resultados/`: tablas (csv) y mapas (png) generados por el script.

## Ejecución

```
pip install -r requirements.txt
python practica6.py
```

El script muestra por pantalla los pesos, las prioridades locales y globales y la clasificación de cada ejercicio, y guarda las tablas y los mapas en la carpeta `resultados/`.
